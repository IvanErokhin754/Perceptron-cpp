# Однослойный перцептрон на C++ (Perceptron-cpp)

Данный репозиторий содержит лабораторную работу по реализации **однослойного перцептрона** на языке C++ с нуля. Проект предназначен для решения задачи бинарной классификации: автоматического определения готовности человека к спортивной тренировке (`GO` — можно идти в зал, `REST` — сегодня лучше восстановиться) на основе физиологических и психологических признаков текущего дня.

Особенностью данной работы является **полный отказ от использования стандартных контейнеров STL** (таких как `std::vector`) для ключевых вычислительных блоков. Вместо этого с нуля реализованы собственные шаблоны динамических массивов, последовательностей и матричной алгебры.

---

## ⚙️ Основные возможности проекта

* **Собственная математическая библиотека:** Полная поддержка матрично-векторных операций, транспонирования, вычисления норм, функций высшего порядка (`Map`, `Reduce`).
* **Кастомное управление памятью:** Реализация динамического массива (`DynamicArray`) и иерархии последовательностей (`ArraySequence`, `MutableArraySequence`) с ручным контролем выделения и очистки памяти.
* **Алгоритм машинного обучения:** Однослойный перцептрон с сигмоидной функцией активации и мини-батчевым градиентным спуском.
* **Предобработка данных:** Автоматическая Z-нормализация (стандартизация) признаков на основе среднего значения и стандартного отклонения обучающей выборки.
* **Валидация и оценка:** Реализация стратифицированного разбиения выборки (`Stratified Split`) для сохранения баланса классов и расчет метрик: *Accuracy, Precision, Recall, F1-score*.
* **Интерактивный CLI-интерфейс:** Консольный UI для пошагового ввода текущих параметров пользователя с автоматическим учетом медицинских «стоп-факторов».

## 📊 Математическая основа модели

Реализация модели строго опирается на классическую теорию однослойных нейронных сетей. Были использованы следующие формулы:

1. **Прямой проход (Forward Pass):** Вычисляется взвешенная сумма входов с добавлением смещения (bias), после чего результат пропускается через логистическую сигмоиду:
   $$z = w^T x + b = \sum_{i=1}^{d} w_i x_i + b$$
   $$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}$$

2. **Функция потерь:** Используется бинарная кросс-энтропия (Log-Loss) с добавлением численного ограничения (clipping на уровне $10^{-15}$) для предотвращения численной неустойчивости (логарифма от нуля):
   $$L = -\frac{1}{m} \sum_{i=1}^{m} \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

3. **Оптимизация параметров (Градиентный спуск):** Матричное вычисление градиентов функции потерь по весам и смещению на каждом мини-батче:
   $$\frac{\partial L}{\partial w} = \frac{1}{m} X^T (\hat{y} - y)$$
   $$\frac{\partial L}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} (\hat{y}_i - y_i)$$
   Параметры обновляются по правилу: $w \leftarrow w - \eta \frac{\partial L}{\partial w}$, $b \leftarrow b - \eta \frac{\partial L}{\partial b}$, где $\eta$ — скорость обучения (`learning_rate`).

4. **Z-нормализация (Стандартизация):**
   $$x^{\prime}=\frac{x-\mu}{\sigma}$$
   Где $\mu$ и $\sigma$ — среднее и стандартное отклонение, вычисленные по обучающей выборке.

## 📋 Структура признаков (Dataset Feature Map)

Модель оперирует вектором из **14 признаков** (One-Hot кодирование для категориальных параметров сна, настроения и состояния):

| Индекс | Название признака | Описание |
|:---:|:---|:---|
| `0` | `SLEEP_LOW` | Мало сна ( $\le 6$ часов) |
| `1` | `SLEEP_NORMAL` | Нормальный сон (от 7 до 10 часов) |
| `2` | `SLEEP_HIGH` | Много сна ( $\ge 11$ часов) |
| `3` | `STATE_BAD` | Разбитое / ватное / плохое физическое состояние |
| `4` | `STATE_NORMAL` | Нормальное физическое состояние |
| `5` | `STATE_GOOD` | Бодрое / хорошее физическое состояние |
| `6` | `HEAVY_YESTERDAY` | Вчера была тяжелая/интенсивная тренировка |
| `7` | `ATE` | Нормальное регулярное питание за последние несколько часов |
| `8` | `HYDRATED` | Достаточное употребление воды за последнее время |
| `9` | `STRONG_MUSCLE_SORENESS` | Наличие сильной мышечной крепатуры |
| `10`| `MOOD_BAD` | Плохое настроение / стресс / упадок мотивации |
| `11`| `MOOD_NORMAL` | Нормальное, стабильное настроение |
| `12`| `MOOD_GOOD` | Хорошее, приподнятое настроение |
| `13`| `TIME_FOR_RECOVERY` | Наличие времени для полноценного сна и еды после тренировки |

### 🛑 Стоп-факторы (Мгновенный отказ)
В кодовой базе UI заложены жесткие медицинские ограничения. Если пользователь указывает наличие **признаков болезни** или **острой боли/травмы в суставах и связках**, программа мгновенно завершает выполнение с вердиктом `REST`, минуя предсказание нейросети, так как тренировки в таких условиях недопустимы.
